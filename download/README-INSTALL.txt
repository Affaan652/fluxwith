===========================================
     FLUXWITH - POLISHED BLACK THEME
===========================================

INSTALLATION STEPS:
-------------------

1. Extract the zip file:
   unzip fluxwith-polished.zip

2. Go to project folder:
   cd (project folder)

3. Install dependencies:
   npm install

4. Run development server:
   npm run dev

5. Build for production:
   npm run build
